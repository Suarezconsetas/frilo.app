# Wireframes aprobados del sitio Frilo (20-10-2026)

Exportados del lienzo de diseño "Frilo — Sitio web (wireframes)". Cada archivo `.dc.html` es una página o un componente.

- El contenido visible (textos, tablas, preguntas frecuentes y fuentes) es el copy final aprobado.
- Las etiquetas `<x-dc>`, `sc-for`, `sc-if`, `dc-import` y la clase `DCLogic` son del formato del lienzo y no se copian al código: sirven para ver la lógica de las calculadoras (por ejemplo, `diaHabil()` en FechaPago y los tres modos de InteresCompuesto).
- Las imágenes `/_blob/...` son los logos de Frilo (isotipo y wordmark en manzana y oliva, y el ícono de la app). Usa los SVG o PNG oficiales del brand book.
